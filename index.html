Detectamos campos privados con bosques nativos en venta, recaudamos fondos mediante donaciones directas y los compramos para entregarlos al Estado como Parques Nacionales inalienables.

Documentación del Sistema de Diseño

1. Sobre el caso

Organización: Fundación Banco de Bosques.

Público: Donantes individuales, activistas ambientales y empresas socias.

Objetivo web: Visibilizar las tierras amenazadas y convertir visitas en metros cuadrados salvados.

2. Variables del Sistema (CSS Custom Properties)

Definición semántica de variables en :root:

  • --color-primario (#2D5A27): Identidad verde institucional.
  • --color-accion (#D97706): Botones de interacción y donación.
  • --color-fondo (#F4F7F4): Fondo de lectura limpio.
  • --color-texto (#1F2937): Color neutro de alta legibilidad.
  • --color-superficie (#FFFFFF): Tarjetas y contenedores.

3. Inventario de Componentes

  • Átomos: .botom, .navegacion__enlace.
  • Moléculas: .tarjeta-bosque.
  • Organismos: .encabezado, .hero, .documentacion.

4. Decisiones Técnicas

La estructura macro de la página utiliza CSS Grid para organizar el header, las secciones de contenido y el panel de documentación. Las alineaciones internas se resolvieron con Flexbox.

El componente .tarjeta-bosque implementa Container Queries (container-type: inline-size) para ajustar el texto y la imagen según el espacio de su contenedor y no según la pantalla.
