# Trabajo Práctico Final: Sistema de Diseño y Sitio Web
**Estudiante:** Nahuel Agustín Gomez  
**Materia:** Seminario de Diseño Multimedial - Facultad de Artes (UNLP)  
**Proyecto:** Fundación Banco de Bosques  

## Descripción del Caso
El proyecto consiste en el diseño y construcción de una plataforma web para la Fundación Banco de Bosques, una organización no gubernamental dedicada a la conservación y salvataje de bosques nativos en Argentina mediante la adquisición directa de tierras estratégicas para su posterior donación al sistema de Parques Nacionales.

## Objetivos del Sitio
- Visibilizar las hectáreas de bosque en riesgo.
- Canalizar donaciones para la compra directa de metros cuadrados de conservación.
- Documentar el sistema de diseño atómico construido para la materia.
